# `TerminalSize` — сервис 3
`TerminalSize` возвращает размер терминала в символах.
Размер записывается в два регистра ВМ.

## Формат
```text
VMCALL 3, <address>, 3
```

## Аргументы
Блок — ровно 3 байта: селектор потока и номера двух регистров.

| Смещение | Размер | Поле    | Значение                                |
|----------|--------|---------|-----------------------------------------|
| 0        | 1      | поток   | 0 = stdin, 1 = stdout, 2 = stderr       |
| 1        | 1      | ширина  | регистр для ширины терминала            |
| 2        | 1      | высота  | регистр для высоты терминала            |

## Результат
Хост записывает размер терминала в символах в регистры. Размер читается после возврата из `VMCALL`. Если у потока нет терминала,
в оба регистра записывается `0`. Сервис всегда возвращает решение `Continue`.
