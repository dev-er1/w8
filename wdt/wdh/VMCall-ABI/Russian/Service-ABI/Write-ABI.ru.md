# `Write` — сервис 1
`Write` записывает строку из памяти ВМ в стандартный поток процесса хоста.
Поток выбирается аргументами.

## Формат
```text
VMCALL 1, <address>, <size>
```

## Аргументы
Блок — выводимая строка с байтом потока и байтом кодировки в начале:

| Смещение | Размер  | Поле      | Значение                           |
|----------|---------|-----------|------------------------------------|
| 0        | 1       | поток     | 0 = stdin, 1 = stdout, 2 = stderr  |
| 1        | 1       | кодировка | кодировка строки                   |
| 2        | size -2 | данные    | байты строки в указанной кодировке |

- У блока нет фиксированного размера: длина задаётся операндом `size` инструкции `VMCALL`.
- `size < 2` — заголовок неполный, хост не может раскодировать данные: ошибка формата аргументов.
- В stdin записать нельзя, поэтому `поток == 0` — ошибка.
- Хост конвертирует строку в UTF-8 и записывает её в поток.
- После каждого вызова хост сбрасывает буфер: вывод виден немедленно, а перемешивание с другим потоком предсказуемо.

## Кодировки
Байт кодировки — второй байт блока:

| Значение | Кодировка | Статус           |
|----------|-----------|------------------|
| 0        | ASCII     | поддерживается   |
| 1        | UTF-8     | поддерживается   |
| 2        | UTF-16 LE | поддерживается   |
