# `IsInTerminal` — сервис 2
`IsInTerminal` проверяет, подключён ли стандартный поток процесса хоста к терминалу.
Результат записывается в регистр ВМ.

## Формат
```text
VMCALL 2, <address>, 2
```

## Аргументы
Блок — ровно 2 байта: регистр для записи результата и селектор потока.

| Смещение | Размер | Поле    | Значение                          |
|----------|--------|---------|-----------------------------------|
| 0        | 1      | регистр | регистр для результата            |
| 1        | 1      | поток   | 0 = stdin, 1 = stdout, 2 = stderr |

## Результат
Хост записывает в регистр `1`, если поток подключён к терминалу, и `0` в противном случае.
Читать регистр нужно после возврата из `VMCALL`. Сервис всегда возвращает решение `Continue`.
