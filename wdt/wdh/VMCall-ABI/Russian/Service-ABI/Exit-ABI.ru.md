# `Exit` — сервис 0
`Exit` завершает ВМ с кодом выхода. Код возвращается наружу: например, `w8c run` завершается с этим же кодом.

## Формат
```text
VMCALL 0, <address>, 1
```

## Аргументы
Блок — ровно 1 байт: номер регистра, в котором хранится код выхода.

| Смещение | Размер | Поле           | Значение               |
|----------|--------|----------------|------------------------|
| 0        | 1      | номер регистра | регистр с кодом выхода |

## Код выхода
Код читается из регистра в момент вызова `VMCALL`. `0` — успех, любое другое значение — ошибка.
